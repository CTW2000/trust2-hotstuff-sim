# 论文数字索引（对应论文 v12，git 标签 `paper-v12`，2026-11-12）

本文件按"论文中的数字 → 结果文件 → 记录与配置"列出原型实验，方便第三方从仓库重新汇总。
- 结果文件都在 `prototype/benchmark/results-p5/`。
- 配置写在对应 DESIGN.md 小节与 `p5.py`、`fork_local.py` 的函数里；每个结果文件的每一行都记录了该次运行的全部参数。
- 汇总方法：`python3 p5.py report` 生成各 `.md`；局部实验的统计由 `localstat.py` 在运行时写入 CSV。
- 现行规范见 `SPEC.md`。

**关于版本的说明：** "版本"一列标出数字测于哪个协议版本：
- "旧换表"：每 100 个视图换表，下一张表在换表时才确定；
- "最终规则"：下一张表提前一个纪元确定，纪元 25 个视图；
- "最终规则 + H2/H4/E2"：§15.24 之后。

表 3、图 2 和 CPU 开销测于旧换表，最终规则下只有抽查；按计划将在全部改动完成后统一重跑（审稿意见 R7）。
